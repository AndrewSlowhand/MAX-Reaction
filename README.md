# MAX Reaction

Автоматизация реакций и действий в чат-ботах MAX через браузер.

Проект предназначен для автоматизации работы с ботами MAX, когда у разных организаций используются разные адреса ботов, но принцип взаимодействия одинаковый.

> **Важно:** с версии 1.3.1 для работы с установленным приложением MAX рекомендуется использовать **прямой адрес веб-версии MAX** (`https://web.max.ru/...`). Это предотвращает перехват ссылки установленным приложением MAX.

## Возможности

- автоматический запуск MAX через встроенный Chromium;
- работа через веб-версию MAX;
- автоматическая обработка кнопки **«Открыть в браузере»**, если она появляется;
- установка реакции 👍, если она доступна;
- нажатие **«Полезно»**, если кнопка есть;
- нажатие 🔥, если реакция доступна в посте;
- сохранение состояния уже обработанных сообщений;
- поддержка нескольких профилей MAX;
- ежедневный запуск через Планировщик заданий Windows;
- скрытый запуск без окна CMD;
- portable-сборка: на конечном компьютере Python устанавливать не требуется.

## 1. Указать адрес веб-версии бота

Откройте:

```text
bot_url.txt
```

и укажите **адрес нужного чата/бота в веб-версии MAX**, например:

```text
https://web.max.ru/YOUR_CHAT_ID
```

MAX официально предоставляет веб-версию по адресу `https://web.max.ru/`.

### Как получить адрес

1. Откройте `https://web.max.ru/`.
2. Войдите в свой профиль MAX.
3. Откройте нужного бота/чат.
4. Скопируйте адрес из адресной строки браузера.
5. Вставьте его в `bot_url.txt`.

> Не указывайте в публичном репозитории URL конкретного учреждения или другой адрес, который вы не хотите публиковать.

## 2. Первый запуск

Запустите:

```text
login.bat
```

Откроется встроенный Chromium с веб-версией MAX.

Если профиль ещё не авторизован, выполните вход в MAX.

После авторизации скрипт продолжит работу с указанным чатом/ботом.

## 3. Ежедневный запуск

Для обычной проверки:

```text
daily.bat
```

Для запуска без окна командной строки:

```text
daily_hidden.vbs
```

Последний вариант удобно использовать в Планировщике заданий Windows.

## Реакции

Режим:

```text
both
```

обрабатывает доступные действия:

- 👍;
- **Полезно**;
- 🔥.

Если конкретной кнопки в посте нет, она пропускается.

## Профили

Можно использовать несколько профилей MAX.

Например:

```bat
login.bat "https://web.max.ru/123456789" account1
```

и:

```bat
login.bat "https://web.max.ru/123456789" account2
```

Данные профилей сохраняются отдельно.

## Сборка

Для сборки проекта на компьютере разработчика используется:

```text
build.bat
```

После сборки можно создать portable-архив:

```text
package_portable.bat
```

На компьютере конечного пользователя Python устанавливать не нужно.

В portable-пакет входит необходимый Chromium.

## Планировщик заданий Windows

Рекомендуемый вариант — запускать:

```text
wscript.exe
```

с аргументом:

```text
daily_hidden.vbs
```

Это позволяет выполнять автоматизацию без видимого окна CMD.

## Требования

### Для компьютера разработчика

- Windows;
- Python;
- интернет для установки зависимостей и Chromium;
- PyInstaller.

### Для готовой portable-сборки

- Windows;
- Python не требуется;
- отдельная установка Chromium не требуется.
