# MAX-Reaction v1.3.1

Patch release focused on compatibility with computers where the MAX desktop application is already installed.

## Changes

- `login.bat` now expects a direct MAX Web URL.
- `bot_url.txt` template changed from `max.ru/...` to `web.max.ru/...`.
- Login no longer depends on the browser's handling of links that can be intercepted by the installed MAX desktop application.
- Updated Russian and English README instructions.
- Version bumped to 1.3.1.

## Important

For this version, use the URL of the required bot/chat as shown in the MAX Web address bar, for example:

`https://web.max.ru/YOUR_CHAT_ID`

The MAX Web version is officially available at `https://web.max.ru/`.
